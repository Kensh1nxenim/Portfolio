# JKB Portfolio (Next.js + Tailwind)

A clean, modern developer portfolio for **John Kenneth Barrameda**.

## Quick Start

```bash
# 1) Install deps
npm install

# 2) Run dev server
npm run dev

# 3) Build for production
npm run build && npm start
```

## Customize

- Edit **app/page.tsx** hero text & contact info.
- Replace **public/resume.pdf** with your real PDF.
- Update **data/projects.ts** with your repos & demo links.
- Change the favicon in **public/favicon.ico**.

## Deploy to Vercel

1. Push this folder to a new GitHub repository.
2. Go to vercel.com → New Project → Import your repo → Framework: Next.js.
3. Click Deploy. Done!

## Notes
- Contact form is static; connect to Formspree or your own API.
- Strict TypeScript + Tailwind 3 + Next.js 14 (app router).
